# Research Protocol

## Evidence order

Use primary sources first: filings, earnings materials, call transcripts, investor presentations, and company releases. Add reputable market/industry reporting and substantive independent analysis to frame contested views. Prefer original sources over aggregators.

## Price and catalyst discipline

- Run the bundled price analyzer rather than moving a raw daily series into context.
- Treat every flagged move as a date to investigate, not proof of a catalyst.
- Compare the target and each benchmark or peer on common actual trading dates.
- Report target return, comparison return, and excess return separately.
- Anchor the visible cutoff to the final returned trading bar.
- Preserve `no identifiable catalyst` when evidence does not resolve a move.

## Debate and call drift

Steelman the best bull and bear cases. Identify the claim each side believes the market is mispricing and the evidence that would prove it wrong. Trace the changing set of analyst questions over roughly eight quarters; close-read the latest two or three Q&A sections when available. Distinguish facts, management claims, third-party claims, and analyst inference.

## Capability fallbacks

Use transcript, filing, market-data, news, and Quartr capabilities only if available in the active task. If one is unavailable, use another primary-source route where possible and state the gap. Never imply a connector is guaranteed.

## Sources

Every material number, dated catalyst, quotation, and current-debate claim needs a nearby citation in Markdown. For a tearsheet, add each supporting item to the structured `sources` list with a label, optional absolute `https` URL, and a short note naming the supported claim or section. Never invent an attribution.
