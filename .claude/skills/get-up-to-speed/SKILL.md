# Get Up to Speed

Produce a concise public-company briefing that feels like real coverage, not a company brochure. Facts are the floor; the disputed variable, evidence, and evolving debate are the value.

## Workflow

1. Resolve the company and ticker. State the business model in two or three sentences and form a hypothesis about the one variable the stock trades on.
2. Resolve this skill's installed directory, then run `scripts/price_action.py` by absolute path. Pass the active task's explicit output path when using `--out`; never run from or write into the installed skill directory.
3. Map significant moves and major run-up/drawdown endpoints to dated catalysts. If no credible catalyst is identifiable, say so rather than guessing.
4. Reconstruct the bull and bear stories and their inflection points from primary filings, calls, company releases, high-quality industry reporting, and substantive independent analysis.
5. Trace roughly eight quarters of call-theme drift with available summaries, then close-read the latest two or three Q&A sections when transcripts are available. Use Quartr, filing, transcript, and market-data capabilities only when present in the active task; do not describe any connector as guaranteed.
6. Synthesize the crux, tape, steelmanned debate, drivers, question drift, and next catalysts. Read [references/research-protocol.md](references/research-protocol.md) before research.

## Output

Default to inline Markdown and create no files. Use the designed artifact only when the user requests a polished, shareable, or persistent output.

For an artifact, write only under `outputs/get-up-to-speed/<safe-ticker>/` in the active task:

```text
python <skill-dir>/scripts/chart.py <price.json> <output.svg> --annotations <annotations.json>
python <skill-dir>/scripts/tearsheet.py <content.json> <output.html> --chart <output.svg>
```

Read [references/artifact-contract.md](references/artifact-contract.md) before preparing either JSON input. The HTML is self-contained. The chart must be generated by the bundled chart script; the tearsheet rejects unmarked or active SVG.

## Briefing Contract

Use this order:

1. `TICKER — Company · Up to Speed (as of DATE)` and a one-line descriptor.
2. Compact snapshot, with verified dates and sources.
3. One bold crux: the disputed variable and what would resolve it.
4. What it is, briefly.
5. Annotated tape and a compact catalyst timeline.
6. Bull case and bear case, steelmanned.
7. The drivers.
8. What analysts asked then versus now, anchored to the latest call date.
9. Next catalysts, with the key date marked.
10. Sources supporting material claims.

Keep prose short but complete. Separate target return, comparison return, and excess return. Treat the script's yfinance fundamentals as supplemental leads only: verify current price, market cap, shares, and valuation through an available market-data capability or primary source before publishing.

## Boundaries

- Route full initiations, exhaustive filing reviews, and valuation workbooks to `initiation-memo-workflow`.
- Do not infer a catalyst from price action alone.
- Do not paste raw daily price series into context.
- Do not claim current facts without a dated source.
- Do not turn missing transcript or connector access into filler; state the coverage gap.
